# VRM の見た目 MOD

VRM のモデル（`.vrm`）を、プレイヤーの見た目にします。自分は三人称（V）で、マルチプレイのほかの人はいつも見えます。

- 動き：立つ（呼吸）・歩く・走る・跳ぶ／落ちる・ジェットパック・泳ぐ・座る。切り替えはなめらかにつながります。
- まばたき（モデルに Blink の表情があるとき）、視線の上下に合わせて頭が少し動きます。
- 髪などの揺れもの（VRM のスプリングボーン）：走ったり向きを変えたりすると揺れます。
- 歩く方向へ体が向きます。止まっているときは向きを保ちます。
- カメラモードで選んだモーション（`cute_motions` などの MOD の動き）で動きます。
- 色はトゥーン調（明るい面と影の面）。VRM 0.x / 1.0 の両方を読めます。

## 使い方

1. この MOD のフォルダに `.vrm` を置く。
2. `players/vrm.json` に、見た目の定義を1つ書く（モデルごとに1つ。何体でも書けます）。

```json
[{"id": "player1", "extends": "default", "name": "player1（VRM）", "model": "alpedia_player1.vrm",
  "height": 1.68, "radius": 0.3, "model_scale": 1.0}]
```

   - `model`：この MOD のフォルダからの相対パス
   - `height`：当たり判定の高さ（m）。モデルの身長に合わせると、目の高さも合います
   - `model_scale`：モデルの大きさの倍率（VRM は 1 = 実寸）
   - 歩く速さなどは `default`（宇宙飛行士）と同じ。変えるなら `walk_speed` などを足します
3. ワールド設定でこの MOD を入れる。
4. ゲーム中に Esc（一時停止）の「見た目 ◀ ▶」で選ぶ（プレイヤーごと。マルチプレイでは参加した人がそれぞれ選べます）。

モデルはワールドを始めるときに全部読み込みます（ゲーム中に見た目を変えても、ほかの人が来ても、ファイルを読みに行きません）。
読めないモデル（壊れている・VRM でない・人型の骨が足りない）なら、そのときにエラーの一覧が出てワールドは始まりません。
ファイルを差し替えたら、ワールドを始め直すと反映されます。

マルチプレイでは、この MOD（`.vrm` も含めて）は参加する人に自動で届きます。
VRM にはモデルの作者が決めた利用条件があるので、ほかの人に配ってよいモデルかどうかは確かめてから使ってください
（読み込んだときに `logs/latest.log` に作者が出ます）。

## ファイル

| ファイル | 中身 |
|---|---|
| `code/vrm.py` | VRM（glTF バイナリ）を読む。骨・メッシュ・素材・テクスチャ・まばたき・利用条件 |
| `code/motion.py` | 手で書いた簡単なモーション（状態ごとの姿勢をなめらかに切り替え） |
| `code/spring.py` | 揺れもの（スプリングボーン） |
| `code/view.py` | Panda3D で描く。モデルの形は1つを共有し、骨での変形はシェーダー（GPU）で行う |
| `code/client.py` | 画面側の拡張。見た目の `model` が `.vrm` のプレイヤー（自分・ほかの人）の体を引き受ける |

動きを変えたいときは `code/motion.py` の `target`（状態ごとの角度）を書き換えます。角度はラジアンです。
