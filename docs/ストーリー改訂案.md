# ストーリー改訂案「黒鉄の艦隊」（提案・未実装）

今のチュートリアル（墜落した技術者 → 月へ帰る）を土台にして、約 90 分でクリアできる物語にする案です。
アンケートの声（物語性がほしい）と、学び方の流れの改善（フィードバック制御が急、サバイバル要素が分からない）をあわせて直します。

## 方針

- **学ぶ順番をなめらかに**：決まった動き（オープンループ）→ ずれを見て直す（フィードバック）→ 遠隔操作 → 乗り物 → 資源と工場 → 自動航行 → 矢印（ベクトル）を使った迎撃 → ロボット
- **章ごとに 1 つの山場**と、章の区切りの短いムービー（15〜60 秒）。ムービーの合計は約 8 分
- **主人公が映らないドラマと艦隊戦は、あらかじめ描いておく**（movies/ の道具。今回のパイロット版と同じ作り方）。
  主人公が映る場面は、同じ仕組み（カメラの動き・役者・字幕）をゲームの中でそのまま再生する
- **重くしない**：物語の構築物はすべて完全な剛体で動かす。遠くの船は箱だけの張りぼてか、街のように四角い塊にまとめる。
  破片やミサイルの煙は構築物ではなく光の粒で描く

## 作り方（技術）

- ムービーは movies/ の道具で作る：場面の Python ファイルに「時刻 → 船・役者・カメラ」を書き、
  ピント（被写界深度）・パン・あおり・ピント送り・揺れ・光のにじみ・字幕を付けて mp4 に書き出す
- ゲームの中では、章の区切りで mp4 を再生（スキップ可）。主人公が映る場面は同じ場面ファイルをゲーム内で実時間再生する
- 艦隊戦・ロボットのプレイ部分：敵のミサイルは小さな剛体の構築物を使い回す（同時に 20〜30 本まで）、
  遠くの艦は張りぼて、壊れた艦は「2〜3 個の塊 ＋ 光の粒の破片」に置き換える

## 決めてほしいこと

1. 登場人物の人数と VRM（今の案は 4 人＋主人公）
2. 声（字幕だけ／仮の合成音声／声優）と BGM の扱い
3. ムービーの画質：1080p の mp4 だと 8 分で約 200〜300 MB。720p にするか、ゲーム内の実時間再生を増やすか
4. 戦いの表現の強さ（対象年齢）
