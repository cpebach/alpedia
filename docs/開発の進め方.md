# 開発の進め方

## フォルダの役割

```
alpedia/
  README.md            このフォルダの案内
  docs/                方針・報告書・この文書
  dev/                 開発版（ゲーム本体の元。ここを直す）
    main/              Python の入口（既定値の表と、Rust を呼ぶだけの薄いファイル。本体は native/ の Rust）
    mods/              MOD（city・story・scenario_blocks・soredemo_cast・lunaport・amatsu・skinmodel(dummy)・
                       cute_motions・bgm・example_mod。Python で書く。書き方は mods/README.md）
    sauce/             本体のテクスチャ・基本定義
    saves/             開発版のセーブ
    config/ logs/      設定・ログ
    lib/               ビルドした Rust（alpedia_core＝物理とゲーム本体、alpedia_view＝画面と音。native から作る。git には入れない）
    native/            Rust のソースと作り方（native/README.md）
      alpedia_core/    物理コア（src/）とゲーム本体（src/game/）
      alpedia_view/    画面（wgpu・winit）と音（rodio）
    tests/             自動テスト
    tools/             設計図・効果音・台本の文書を作り直す道具
    run.py start.bat   起動
  packages/
    windows/           Windows のパッケージ版
      Alpedia/         配る物（Alpedia.exe・同梱の Python・game/ にゲーム一式）
      build/           パッケージを作るスクリプト
      パッケージを作る.bat
    linux/             予定地
  movies/              シナリオのムービーを描く道具（movies/README.md）
```

- 開発版とパッケージ版のセーブ・設定は別々です（`dev/saves` と `packages/windows/Alpedia/game/saves`）。
- パッケージ版の `game/` は、`dev/` から作ったコピーです。**直すのは `dev/` だけ**にして、パッケージは作り直します。

## 開発版を動かす

- 起動：`dev/start.bat`（または `dev` で `python run.py`）。必要なライブラリは `dev/requirements.txt`（numpy・pillow・av）と、
  `dev/lib/` のビルドした Rust（下の「Rust を作り直す」。**無いと起動しません**）。
- テスト：`dev` で `python -m unittest discover -s tests -v`
  （コア・Rust の物理コア・MOD の読み込み・街・マルチプレイ・シナリオの通しを、画面なしで確かめます。110 件で約 5 分）
- 描画なしで動かす：`dev` で `python run.py --headless --steps 600`

## Rust を作り直す（native/ を変えたとき）

ゲームの本体（物理・ワールド・機器・画面・UI・音・通信）は Rust です。`dev/main/` の Python は入口だけなので、
ゲームの動きを直すときは `dev/native/` の Rust を直して作り直します（MOD とゲーム内のプログラムは Python のまま）。

`dev\native\build_windows.bat` をダブルクリック。次のものを作ります（`dev/native/README.md`）。

- 開発版用：`dev\lib\alpedia_core.pyd`・`alpedia_view.pyd`（この PC の Python 3.10 以上で使える形）
- パッケージ版用：`dev\lib\` と `packages\windows\Alpedia\game\lib\` の
  `alpedia_core.cp312-win_amd64.pyd`・`alpedia_view.cp312-win_amd64.pyd`（同梱の Python 3.12 用）

どちらも無いと起動しません（前の版の numba・Panda3D・ursina の予備はもうありません）。

## パッケージ版を作り直す（dev/ を変えたとき）

`packages\windows\パッケージを作る.bat` をダブルクリック。`dev/` の main・mods・sauce・lib・README などを
`packages/windows/Alpedia/game/` に入れ直します。パッケージ版のセーブ・設定・自分で足した MOD は消えません。
Rust を変えたときは、先に `build_windows.bat` で作り直してからにします。

- `--skip-runtime`：ゲーム部分だけ更新（速い）　`--zip`：配布用の zip も作る（`packages/windows/dist/`）
- 詳しくは `packages/windows/README.md`
