# 開発の進め方

## フォルダの役割

```
alpedia/
  README.md            このフォルダの案内
  docs/                方針・報告書・この文書
  dev/                 開発版（ゲーム本体の元。ここを直す）
    main/              本体のコード（main/client/ は画面）
    mods/              MOD（survival・city・example_mod・skinmodel(dummy)。書き方は mods/README.md）
    sauce/             本体のテクスチャ・基本定義
    saves/             開発版のセーブ
    config/ logs/      設定・ログ
    lib/               Rust の物理コア（alpedia_core.pyd。native から作る）
    native/            Rust の物理コアのソースと作り方（native/README.md）
    tests/             自動テスト
    run.py start.bat   起動
  packages/
    windows/           Windows のパッケージ版
      Alpedia/         配る物（Alpedia.exe・同梱の Python・game/ にゲーム一式）
      build/           パッケージを作るスクリプト
      パッケージを作る.bat
    linux/             予定地
```

- 開発版とパッケージ版のセーブ・設定は別々です（`dev/saves` と `packages/windows/Alpedia/game/saves`）。
- パッケージ版の `game/` は、`dev/` から作ったコピーです。**直すのは `dev/` だけ**にして、パッケージは作り直します。

## 開発版を動かす

- 起動：`dev/start.bat`（または `dev` で `python run.py`）。必要なライブラリは `dev/requirements.txt`。
- テスト：`dev` で `python -m unittest discover -s tests -v`
  （コア・Rust の物理コア・MOD の読み込み・街・マルチプレイを、画面なしで確かめます）

## Rust の物理コアを作り直す（native/ を変えたとき）

`dev\native\build_windows.bat` をダブルクリック。次の2つを作ります（`dev/native/README.md`）。

- 開発版用：`dev\lib\alpedia_core.pyd`
- パッケージ版用：`packages\windows\Alpedia\game\lib\alpedia_core.cp312-win_amd64.pyd`

無くても numba で動きます（遅くなるだけ）。

## パッケージ版を作り直す（dev/ を変えたとき）

`packages\windows\パッケージを作る.bat` をダブルクリック。`dev/` の main・mods（本体に入っている MOD）・sauce・README などを
`packages/windows/Alpedia/game/` に入れ直します。パッケージ版のセーブは消えません。

- `--skip-runtime`：ゲーム部分だけ更新（速い）　`--zip`：配布用の zip も作る（`packages/windows/dist/`）
- 詳しくは `packages/windows/README.md`

## 文書のありか

| 文書 | 場所 |
|---|---|
| 遊び方・操作・仕組み・コード構成 | `dev/README.md` |
| MOD の作り方（マルチプレイ対応も） | `dev/mods/README.md` |
| VRM の見た目 MOD | `dev/mods/skinmodel(dummy)/README.md` |
| Rust の物理コア | `dev/native/README.md` |
| パッケージ版（GPU 高速化・作り方） | `packages/windows/README.md` |
| 方針・報告書 | `docs/` |
