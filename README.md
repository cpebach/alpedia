# Alpedia（プロトタイプ）

Minecraft と KSP を組み合わせたような、物理演算付きボクセルサンドボックス。
「方針.txt」に沿って作った、一通り動く最初の土台です。

## 起動

1. Python 3.10 以上を入れる
2. このフォルダで `pip install -r requirements.txt`
3. `start.bat` をダブルクリック（または `python run.py`）

起動するとメニュー画面が出ます（初回はサンプルワールド `demo` が自動で作られます）。

### メニュー画面

- **ワールド一覧**: クリックで選択、選択中をもう一度クリックするか「遊ぶ」で開始
- **新規作成**: 名前（半角英数字）、テンプレート（空／デモ／チュートリアル）、惑星（球体／地球型）、クリエイティブ、ボクセルサイズ、重力倍率、自動削除、MOD を選んで作成
- **ワールド設定**: 選択中のワールドの上記設定と、自動削除の距離・時間・頂点数、MOD の ON/OFF を変更
- **削除**: 確認画面のあと、ワールドのフォルダごと削除（元に戻せません）
- **ゲーム設定**: 解像度・フルスクリーン・視野角・描画距離・地表の細かさ・マウス感度・物理計算の精度（config/settings.json に保存）

ゲーム中に Esc で一時停止メニュー（再開／保存／メニューへ戻る／終了）が開きます。

```
python run.py --world 名前        メニューを飛ばして指定ワールドで起動（無ければ空のワールドを作成）
python run.py --headless --steps 600   描画なしでシミュレーションだけ実行（動作確認用）
```

## 操作

| キー | 動作 |
|---|---|
| WASD / マウス | 移動 / 視点 |
| Space / Ctrl | ジャンプ・上昇 / 下降（ジェットパック時） |
| F | ジェットパック ON/OFF |
| 左クリック | ボクセル削除・地面を掘る |
| 右クリック | 選択中の素材・機器を設置（地面に置くと新しい構築物） |
| ホイール・1〜9 | アイテムバー（画面下の9枠）から素材・機器を選ぶ |
| I | インベントリ：すべての素材・機器をアイコンで表示。クリックで持ち上げてアイテムバーの枠へ（Esc で閉じる） |
| R | 機器の向きを変更 |
| N | 目の前の空中に新しい構築物を作る |
| E | 機器の操作（バルブ開閉・コンピューター起動・手回し発電 など）／操縦席に座る・降りる |
| P | 機器の設定メニュー：名前の変更（すべての機器）／コンピューターのプログラム編集／アクチュエーターの動作設定 |
| V | 三人称視点 |
| M | 目印の切替（最寄りの街 → 自宅 → なし） |
| K | マップ（訪れた都市・都市への助言） |
| F5 / F9 / F8 | 保存 / 見ている構築物を OBJ 出力 / 読み込みメニュー |
| F10 / F11 / F12 | （ursina 組み込み）描画モード切替（ワイヤーフレームなど。もう一度押すと順に戻る）/ フルスクリーン / 開発用表示 |
| Esc | 一時停止メニュー（再開・保存・メニューへ戻る・終了） |

操縦席に座っている間は、推進機に割り当てたキー（既定 Space）で噴射、X でアクチュエーターの設定動作を実行。
キー入力はコンピューターのスクリプトからも読めます。

### チュートリアル

メニューの「新規作成」でテンプレートを「チュートリアル」にすると、看板に沿って奥へ進みながら
移動 → 建築 → ブロックの形（球・円柱・スロープ）→ 物理 → 機器 → コンピューターと看板 → アクチュエーター →
棒の姿勢制御（ブロックプログラミング）→ ロケットの組み立て → 軌道投入 → 無線とドローンの遠隔操作
までを順に学べるワールドができます（初回起動時は自動で `tutorial` も作られます）。

- **ブロックの形**: 1つ／2つ／階段／板の見本と、スロープを転がるゴムの玉があります。
- **看板**: 倒れないように、岩の台座（5×3）と十字の支えの上に柱を立てています。
- **棒の姿勢制御**: 揺らしモーターで揺れ続ける台の上の棒を、アクチュエーター（姿勢モーター）とブロックプログラムで
  一定の角度に保ちます。お手本の装置（完成プログラム入り）と課題の装置があり、看板の手順どおりにブロックを並べると完成します。
  棒の世界から見た角度は、ブロックの「機器の値 → 出力の向き」、Python では `actuator.output_angle` で取得できます。
- **軌道投入**: 完成形の「見本ロケット」と、重力ターンで自動的に軌道に乗るブロックプログラム `scripts/orbit.blocks.json`
  （変換後の `orbit.py`）付きです。4つの推進機に「推進機前左・前右・後左・後右」と名前を付け、ブロックで
  「前への傾き」が「目標」に近づくよう出力に差をつけています。Python 版の `orbit_python.py` もあります。
  自分で作ったロケットには、ブロックエディタの「別のファイルを開く」で orbit を開いて保存すると設定できます。
  操縦席に座っている間は画面左上に遠点・近点が表示されます。
- **無線とドローン**: ロケットの先に「ドローンの操縦台」と「ドローン」があります。操縦台の操縦席に座ると（E）、
  押したキーが無線（チャンネル `drone`）でドローンに送られ、W/S/A/D で前後左右（操縦台の向きが前）、
  Space / Left Shift で上昇・下降、X で着陸／離陸します。操縦台の画面に高度・速さ・燃料・電波の状態が出ます。
  電波が切れる（届く距離の外・アンテナが OFF など）と、ドローンはその場でゆっくり降りて着陸します。
  仕組みは `scripts/drone.py`（ドローン側）と `scripts/drone_remote.py`（操縦台側）。

### 惑星の種類

新規作成の「惑星」で選べます（空のワールド・デモ）。

- **球体（テラ）**: なめらかな起伏の球体の惑星（従来どおり）。
- **地球型（ガイア）**: 山脈・丘・海・池（水たまり）・洞窟のある惑星。出現地点のまわりは平らな草原で、
  すぐそばに池、少し先に洞窟の入口、-Z 方向に山があります。
  - 水：海と池の水面より下では、構築物に浮力（押しのけた水の重さ）と抵抗がかかります。木は浮き、鋼鉄は沈みます。
    気密の空洞も水を押しのけます。プレイヤーは泳げます（Space で上、Ctrl で下、WASD で移動）。
  - 洞窟：地中をうねって続くトンネルと広間。入口から歩いて入れます。中は暗めに描かれます。
  - 山の横から掘ってトンネルを作ることもできます（掘った跡や洞窟の中は詳細なメッシュで描画）。
  - 地形はすべて `seed` から作られるので、`sauce/base/planets/base.json` の `seed`・`mountain_height`・
    `caves`（洞窟の数）・`ponds`（池の数）・`sea_level` を変えると別の地形になります（MOD でも定義できます）。

### demo ワールドで試せること

- **ロケット**: 上段のコンピューター（「ホバー制御」）を E で起動すると、`scripts/hover.py` で高度12mに浮きます。
  起動中に操縦席に座ると W/S で高度、矢印キーで移動。Space で全開噴射（コンピューター停止中も可）。
- **気密キャビン**: 中が 2×2×2 の空洞。通気口が空気タンクから与圧します（狙うと気圧が見えます）。E で給気/排気切替。
  壁を1つ壊すと空洞ではなくなります。
- **木の塔・水・粘土**: 下の方を壊すと倒れたり、ちぎれたり、液体・粘土は崩れて再結合します。
- F8 の読み込みメニューで `imports/pyramid.obj` を選ぶと、大きさを決めてボクセル化して置けます。

## 仕組み

- **丸いブロック**: ブロックは球の形で、結合したブロック同士の間は埋まります（2つなら両端が丸い円柱、
  階段状に並べるとスロープ、平らに並べると角の丸い板）。見た目と当たり判定（地面・構築物どうし・プレイヤー）は同じ形です。
  形は結合に沿って作られるので、ちぎれると間の埋まりも消えます。テクスチャは箱型の投影で貼っています。
  この形を作るのに `scikit-image` を使います（入っていない場合は従来の立方体で表示されます）。
  ブロックを狙ったときの枠と、OBJ 読み込み時のボクセル化は立方体のままです。OBJ 出力は丸い形で書き出します。
- **ポリゴンのボクセル**: 各ボクセルは自分の8頂点を持ち、隣のボクセルと同じ位置の頂点同士が結合しています。
  素材の `stiffness`（形の保ちやすさ）、`joint_stiffness`（頂点間の動きにくさ）、`break_distance`（ちぎれる距離）、
  `plasticity`（曲がったまま戻らない度合い）、`rebond`（近づくと再結合）で、固体・液体・靭性・硬度を表現します。
  ちぎれると自動で別の構築物に分かれます。静止した構築物は計算を止めて（スリープ）軽くしています。
- **電力**: 配線不要。同じ構築物にある発電機・バッテリー・消費機器で共有されます。
- **配管**: 配管ポートを持つ機器（配管・タンク・推進機・発電機・通気口・バルブ）が、結合した連続ボクセルで繋がっている必要があります。閉じたバルブは流れを止めます。
- **気密**: ボクセルで完全に囲まれた空洞を自動で検出し、通気口で与圧・減圧できます。
- **アクチュエーター**: 向きを付けて置いたブロックの「出力面」の先を動かします。回転（角度・速度）、押し出し／引き込み
  （最大ブロック1つ分・速度）、分離、結合（別の構築物とも可）ができ、電力を使います。操作は2通り：
  P で動作の種類・量・速度を設定して E で実行（操縦席では X）、またはコンピューターから
  `a = api.device("名前")` → `a.rotate(90, speed=45)` / `a.extend(1.0)` / `a.retract(1.0)` / `a.detach()` / `a.attach()`。
  回転・押し出しは格子に沿って結合しているブロックに伝わります（ずれて結合した場合は固定のみ）。
- **アンテナと無線通信**: アンテナ（電力 100 W、届く距離 3000 m）のある構築物どうしは、コンピューターから情報をやり取りできます。
  `api.send("チャンネル", 情報)` で送り、`api.receive("チャンネル")`（前回より後に届いたもののリスト）か
  `api.latest("チャンネル")`（いちばん新しいもの）で受け取ります。情報は数値・文字・True/False/None と、それらのリスト・辞書。
  届く距離は送る側と受ける側のアンテナの短いほうで、送ったものは 2 秒間だけ届きます。自分の構築物が送ったものは受け取りません。
  アンテナが無い・電力が来ていない・OFF（E で切り替え）の構築物では、この3つの関数はエラーになります（`api.antenna` で確かめられます）。
  電力・信号は構築物の中で共有なので、アンテナは構築物のどこにあっても使えます。ブロックプログラムでは「通信」の
  「チャンネル □ に □ を送る」と、値の「通信の受信値」「チャンネル □ に届いている」「アンテナが使える」を使います。
- **機器の記号**: 機器ブロックの表面には、インベントリのアイコンと同じ種類の記号が付きます。向きのある機器（推進機・
  アクチュエーター・コンピューター・操縦席）は、横の面の黄色い ▲ が機器の向き、向いている面は黄色い輪、反対側の面は薄い記号です
  （推進機は ▲ の方向に押します）。`config/settings.json` の `graphics.decal_distance`（既定 30 m）より遠い構築物では表示しません。
- **機器の名前**: 機器を見て P（コンピューター・アクチュエーターはメニュー内の「名前を変更」）で名前を付けられます。
  同じ名前の機器はコンピューターからまとめて動き、名前を分けると `api.device("推進機左")` やブロックの機器選択で個別に制御できます。
  「同名に番号を振る」で同じ名前の機器に 1, 2, 3… と番号を付けられます。日本語は「左・右・前・後…」などのボタンで付け足せます。
  名前を変えると、その構築物のブロックプログラム内の機器名も自動で置き換わります。
- **ブロック（ノード）プログラミング**: コンピューターの P 画面で「ブロックで編集」を押すと、スクラッチのように
  ブロックを並べてプログラムを作れます。左のパレットのブロックを押すと選んだ行の下（「＋ここに追加」を選べばその中）に入り、
  白い枠をクリックすると数値・センサー（高度・速さ・遠点・遠点までの時間・前への傾き・右への傾き・傾く速さなど）・計算・比較・変数・キー・機器を選べます。
  イベント（起動したとき／ずっと／キーを押している間／押したとき／条件になったとき）、制御（もし・でなければ・くり返し・タイマー・停止）、
  機器（推進機の出力・バルブ・ON/OFF）、アクチュエーター（回転・押し出し・引き込み・分離・結合）、表示、変数のブロックがあります。
  保存すると `scripts/<名前>.blocks.json` と、Python に変換した `<名前>.py` ができ、コンピューターはそれを実行します。
  「Python をコピー」で変換したコードをクリップボードにコピー、「Python で開く」で中身を確認できます
  （Python 側で保存すると Python モードに切り替わります。Python からブロックへの変換はありません）。
- **Python 制御**: コンピューターを見て P でスクリプトエディタが開きます。表示・編集・保存（Ctrl+S）・保存して実行（Ctrl+R）・停止、
  ファイルの切り替えや新規作成、print の出力とエラー行の確認、API 一覧の表示ができます。ファイルは `scripts/` に保存され、
  保存したファイルがそのコンピューターに設定されます。E で起動/停止。`tick(api)` が周期的に呼ばれます。
  `api.display("文字", width=3)` でコンピューターの表面に文字を表示できます（停止しても残るので看板として使えます）。
  `api.orbit()` で遠点・近点などの軌道情報も取得できます。
  エディタは Windows の等幅日本語フォント（BIZ UDゴシック／MS ゴシック）を使います（`graphics.code_font` で変更可）。
- **OBJ**: F9 で `exports/` に `.obj`・`.mtl`・`.alp.json`（素材割当て＋ボクセルデータ＋使っているプログラム）を出力。
  F8 で**読み込みメニュー**が開きます。
  - 一覧：このワールドの `imports/`・`exports/` と、ほかのワールドの `exports/`（コピーしなくても持ってこられます）。
    「imports を開く」でフォルダを開き、ファイルを置いたら「一覧を更新」。
  - ゲーム内で作った構築物（`.alp.json` にボクセルデータあり）は、ボクセル・機器・結合をそのまま再現し、
    プログラムも `scripts/` に入ります（同じ名前で中身が違うものが既にあれば、そちらを残します）。
  - 外部の OBJ（Blender など）は、**大きさ（いちばん長い辺 m）**・**細かさ（ボクセル 0.25/0.5/1 m）**・**素材**を指定してボクセル化します。
    元の大きさが 0.5〜40 の範囲ならその数値を m として、外れていれば（mm 単位など）8 m にして始めます。
    `.alp.json` の `"materials"`（usemtl名→素材ID）・`"scale"`・`"voxel_size"` があれば最初の値に使います。
  - 置いたときの大きさ・ボクセル数・素材と、サバイバルでは必要な資源と手持ち（足りないもの）を確認してから
    **OK** で目の前に置きます。何もせずやめるときは**閉じる**（または Esc）。
- **世界の広さ**: 制限なし（描画は浮動原点）。`world.json` の `cleanup` で、プレイヤーから一定距離以上・一定時間・
  電力なし・頂点数以下の構築物を自動削除します（`"enabled": false` で無効化）。
- **サバイバル**: `world.json` の `"creative": false`（新規作成で選択）で、設置に資源が必要になります。詳しくは下の「サバイバル」。

## サイバーパンクの街

惑星の地表と軌道上に、ネオンの光るビル街がほぼ一定の間隔で自動的にできます（惑星の seed から毎回同じ場所・同じ形）。

- **場所**: 惑星の地表に約 520 m おき（月は約 300 m おき）の候補地から、作れる所を選びます。候補地がだめなら近くを何か所か探し直し、
  街どうしは外周で 240 m 以上離します。小惑星には小さな前哨基地、惑星と月のまわりの軌道上にステーション型の「軌道都市」。
  - **山あい**: 15 m 四方の区画ごとに舗装した台を段々に作るので、斜面にも街ができます（高低差が大きすぎる急斜面は除く）。
  - **海沿い**: 水の上の区画は桟橋（水面より約 1.2 m 高い台）になり、水から階段で上がれます（ほとんど水の上・深い海は除く）。
  - 作らない所：出現地点のまわり。
- **歩きやすい地面**: 区画ごとに舗装し、高さは 25 cm 刻みでそろえます。55 cm までの段差は歩くだけで上れます（プレイヤーの自動の段差越え）。
  それより高い段差には区画の縁に沿った階段（1段 22 cm 以下、上に踊り場）、街の外の地面との間にも階段（地面に届くまで下りる）。
  1 m 以上の段差の縁には光る線が付きます。舗装・階段は壊れません。
- **目印**: 画面に最寄りの街の名前と距離を表示します（画面の外にあるときは端に ◀▶▲▼ で方向）。**M** で表示切替。
  地表近く（高度 60 m か惑星の半径の 15% の大きい方まで）では、軌道都市が近くても、いる惑星の地表の街（墜落した街を含む）を優先します。
- **描画の軽量化**: 街の外周から 100 m より遠い街は、建物を1つの箱だけで描く簡略表示（窓の模様・ネオン・看板・連絡通路なし、
  色にネオン色を混ぜて屋上を光らせる）。近づくと窓やネオンのある詳細表示になります（離れるときは 120 m で戻す）。
  2500 m より遠い街と、画面の外・惑星の裏側の街は描きません。箱の内側の面も描きません。
  距離は `config/settings.json` の `graphics.city_detail_distance`・`graphics.city_view_distance` で変えられます。
- **当たり判定**: 構築物もプレイヤーも建物にぶつかり、上に乗れます。右クリックで建物の上にブロックを置けます。
- **壊れる**: 約 7 m/s 以上でぶつかった建物は、低く崩れて暗くなり、ネオンが消えた「壊れた見た目」に。
  約 18 m/s 以上か、壊れた建物にもう一度強く当たると消えます。すべて壊れると「壊滅」。
- **軌道都市を動かす**: 街全体を1つの剛体（質量は数百 t）として軌道を計算します。
  - 構築物でゆっくり押すと、その分だけ街が動きます（押した力の反動）。
  - 街に直接置いたブロックは街に**固定**されます。既存の構築物も、街に触れた状態で機器以外のブロックを E で固定／切り離しできます。
    固定した構築物の推進機を噴かすと街ごと加速し、軌道を変えたり落としたりできます（例：推進機2基で約10秒噴かすと近点が約200 m 下がる）。
  - 地面に落ちると、ぶつかった建物が壊れ、止まった所で「墜落した街」になります（台座は残ります）。
- **保存**: 壊れた建物と軌道都市の位置・速度だけを `world.json` の `city_state` に保存します。
  ワールド設定の「サイバーパンクの街」で ON/OFF（既存のワールドでも ON。チュートリアルは OFF）。
  既存のワールドで、読み込んだ時点で構築物と重なる建物は最初から取り除き、構築物が街の地面（舗装・階段）と重なる場合はその街ごと作りません。

## 街の暮らし（通貨・NPC・取引・部屋）

- **通貨**: クレジット（所持品の「クレジット」）。サバイバルで街のあるワールドに入ると最初に 200 もらえます。
- **内装のある建物**: どの街にも、店（商人）・不動産屋・住宅（何部屋か並ぶ）があります。地面の階が店や部屋で、上にビルが重なっています。
  入口の看板の色：店＝橙、不動産屋＝緑、部屋＝水色。中には明かり・カウンター・棚・ベッド・収納箱があります。軌道都市は甲板の上、
  前哨基地（小惑星）は店だけ。
- **NPC**: プレイヤーのような簡素な姿（体・頭・光るバイザー）。商人と不動産屋は店の中、住民は広場や甲板を歩いています。
  見て **E** で話す（住民はほかの街の値段のうわさなどを教えてくれます）。
- **取引（サバイバルだけ）**: 商人（またはカウンター）を見て E。1・10個ずつ・全部 を売り買いできます。店から買う値段は基準の 1.1 倍、
  店に売る値段は 0.9 倍。どの街でも、鉱石を買って精錬して鉄とケイ砂を売るだけで少しもうかる（約 +5〜40%）くらいの甘めの値段です。
- **地域で値段が変わる**（基準の何倍か。ほかに街ごとに ±7%）

  | 地域 | どんな街 | 安い | 高い |
  |---|---|---|---|
  | 平地の街 | ふつうの街 | — | — |
  | 海辺の街 | 桟橋のある街 | 燃料 0.5・水 0.3 | 硫黄 1.3 |
  | 火山の街 | 硫黄の採れる高い山の街 | 硫黄 0.4・燃料 0.85 | 鉄 1.15・部品 1.1 |
  | 軌道都市 | 軌道上のステーション | 鉱石 0.6・硫黄 0.6・星鉱石 0.6・鉄 0.7 | **燃料 3.0・水 3.0**・部品 1.3 |
  | 辺境の基地 | 月・小惑星 | 星鉱石 0.6・鉱石 0.9 | 燃料 1.8・水 2.0・部品 1.2 |

  例：海辺の街で燃料を買って軌道都市で売る、火山の街で硫黄を買って燃料にする、など。
- **部屋（サバイバル）**: 不動産屋で買う（平地 約 400、軌道都市 約 900 クレジット）か、値段の 1 割で 60 分（ゲーム内の時間）借りる。
  - 収納箱：資源やクレジットを預けられる（借りる期限が切れても中身は残り、また借りれば出せます）。
  - ベッド：休むと保存して、そこが自宅になります。**M** キーで目印を「最寄りの街 → 自宅 → なし」と切り替え。
  - 建物が壊れて消えると、その部屋は使えません。クリエイティブでは買わなくても使えます（取引はなし・NPC は話すだけ）。
- **保存**: 部屋の持ち主・賃貸の期限・収納箱の中身・自宅は `world.json` の `economy` に保存します。

## マップと都市の思惑

- **K** でマップ（訪れた都市）。街の外周から 30 m まで近づくと「訪れた」になり、マップに載ります。
  天体ごとのタブ・経度と緯度の地図（◇は軌道都市の今の真下）・地域の色・現在地・ニュースを表示します。閉じるボタン / Esc で閉じる。
- **都市の思惑（サバイバル・訪れた都市だけ）**: 都市は「緊張」（0〜100）をためます。
  - **野心**：短い間に大量の取引をされると強気になり（取引の勢いが 400 クレジットを超えた分だけ、最大 3／分）、ほかの都市の**征服**を計画します。
    征服された都市は、取引の傾向（地域）が征服した都市と同じになります。
  - **不満**：訪れてから 25 分取引がないと、2.5／分ずつ不満がたまり、ほかの都市への**攻撃**を計画します。
    滅ぼされた都市は建物の多くが壊れた廃墟になり、NPC はいなくなります（部屋は使えなくなり、収納箱の中身はどの街の不動産屋でも受け取れます）。
  - 取引をすると不満は下がり、何もなければ緊張は少しずつ下がります。
  - 緊張が 70 を超えると、いちばん近い都市を目標に計画を立て（ニュースとマップの赤い枠でわかります）、**12 分後**にまだ緊張が高ければ実行します。
    攻める側の力＝残っている建物の数×（1＋緊張/100）、守る側の力＝建物の数×（1＋0.6×防御）。守る側が上回れば退けます。
  - 速さの目安：放っておいた都市は訪れてから約 65 分、取引しすぎた都市は最短でも約 35 分で行動します。行動のあとは 20 分休みます。
- **助言**（マップで都市を選ぶ。訪れた都市ならどこからでも。通信費 20 クレジット・同じ都市へは 5 分あける）
  - **説得する**：緊張を 35 下げ、取引の勢いを半分に。緊張が 55 未満になれば計画は中止。
  - **防御を促す**：防御 +1（最大 3）を 30 分。攻められても持ちこたえやすくなります。
  - **攻撃の目標を変える**：計画中の都市の目標を、近くのほかの都市に変えさせます。
- 保存は `world.json` の `politics`（訪問・緊張・計画・防御・支配・滅亡・ニュース）。クリエイティブでは動きません（マップは見られます）。

## サバイバル

クリエイティブとの違いは「置くのに資源が要る」「ジェットパックに手持ちの燃料が要る」の2つだけです。

- **最初の所持品**: 鉄 250・ケイ砂 40・機械部品 12・燃料 60。精錬機（鉄100）・手回し発電機・太陽光パネル・タンクを
  すぐ作れ、少しだけ飛べます（既存のサバイバルワールドも、足りない分だけ一度もらえます）。
- **掘ると出るもの**（左クリックで 20 ずつ。狙うと何が出るか表示されます）

  | 場所 | 資源 | 見た目 |
  |---|---|---|
  | ふつうの地面 | 鉱石 | 地面の色 |
  | 山の上の方（テラでは高い所） | 硫黄鉱石 | 黄色いまだら |
  | 洞窟の壁のまわり 3 m・月（ルナ）・小惑星 | 星鉱石 | 紫のまだら |
  | 海・池の水面（クリック） | 水 | いくらくんでも減りません |

- **精錬機**（E で手持ちの原料を入れ、もう一度 E でできた物を受け取る。複数の原料は順番に処理）

  | 原料 | できる物 | 電力 |
  |---|---|---|
  | 鉱石 10 | 鉄 4・ケイ砂 3 | 5 kW × 2 秒 |
  | 硫黄鉱石 10 | 燃料 20 | 5 kW × 2 秒 |
  | 星鉱石 10 | 燃料 5・鉄 8・ケイ砂 6・機械部品 1 | 5 kW × 2 秒 |
  | 水 10 | 燃料 5 | **60 kW** × 2 秒（水は無限なぶん電気を多く使う） |

- **電気**: 手回し発電機（E 1回 5 kJ）、太陽光パネル（燃料なしで 1.5 kW。鉄15・ケイ砂15）、発電機（燃料 1 kg/秒で 20 kW）。
  同じ構築物の中で共有されます。サバイバルで置いたバッテリーは空から始まります。
  発電機で燃料を電気にして水から燃料を作ると必ず損をする（1 kg あたり 20 kJ に対して 24 kJ 必要）ので、
  水の燃料化には太陽光パネルや手回し発電機の電気を使います。発電機は電気の使い道（消費中・バッテリーに空き）があるときだけ燃料を使います。
- **タンクへの給油**: タンクを狙って E で、手持ちの燃料を入れます（入りきらない分は手元に残ります）。
- **ジェットパック**: 噴射している間だけ手持ちの燃料を 1 kg/秒 使います（地上を歩くだけなら減りません）。燃料が 0 だと飛べません。
- **月と小惑星**: 新しく作るワールドには月（ルナ、4 km 先）と小惑星 3 つ（6〜8 km 先）があります。星鉱石が採れるので、
  ロケットで取りに行く価値があります（既存のワールドの天体は変えていません）。
- 量や電力は `sauce/base/devices/base.json`（レシピの `"power"`）・`sauce/base/planets/base.json`（`"deposits"`・
  `"cave_resource"`）・`sauce/base/players/base.json`（`"jetpack_fuel_rate"`）で調整できます。

## 軽量化の仕組み

大きな構築物や多数の構築物でも重くなりにくいように、状況に応じて計算のしかたを切り替えます
（`config/settings.json` の `physics` で ON/OFF・しきい値を変更できます）。

1. **剛体化と静止**（`rigid_enabled`）：重力以外の加速度が小さく（25 m/s² 以下）、形がほとんど変わっていない構築物は、
   ブロックごとの計算をやめて形を保ったまま1つの剛体として動かします。推進機が大きな加速度を出したとき、速くぶつかりそうなとき、
   アクチュエーターが動くとき、ブロックを付け外ししたときは自動でブロックごとの計算に戻ります（壊れ方・曲がり方は残ります）。
   止まっていて、動いている他の構築物に触れていないものは静止扱い（計算しない）にします。
   剛体・静止中の構築物は丸い表面の形を作り直さず、位置と向きだけを動かして描画します。
2. **遠方のレール**（`rails_enabled`, `rails_distance` 既定 400 m）：プレイヤーから遠く、噴射しておらず、地面から離れている
   構築物は、重心の軌道と回転だけを計算します（軌道は正確に保たれます）。近づく・噴射する・地面に近づくと元に戻ります。
3. **チャンク化**（`chunk_enabled`, `chunk_min_voxels` 既定 300）：ブロック数の多い構築物は 4×4×4 ブロックごとのかたまりを
   剛体として扱い、かたまりの境目だけを結合として計算します。境目に大きな力がかかったり、速く地面にぶつかりそうになったりした
   かたまりはブロックごとの計算に戻り、そこで曲がったり折れたりします。アクチュエーター・柔らかい素材のブロックは対象外です。

### 完全剛体モード（ワールド設定）

ワールド設定の「完全剛体モード」を ON にすると、衝突・速度・加速度にかかわらず、構築物は丸ごと1つの剛体として動きます
（曲がらない・ちぎれない・壊れない。軽く、ぶつけても形が保たれます）。

- 地面との接触は剛体として解きます（めり込んだ分を並進＋回転でまとめて押し戻し、摩擦をかける）。跳ね返らずに着地し、
  傾いて落ちれば転がる・倒れるといった動きをします。構築物どうしもぶつかって押し合います。
- **アクチュエーターが動いている間**は、構築物をアクチュエーターの前後で「部分」に分け、部分ごとの剛体を関節でつないで動かします
  （例：人型ロボットなら胴・頭・上腕・前腕・太もも・すね（足）がそれぞれ剛体）。
  - 部分 = アクチュエーターの出力面の結合を切ったときにつながっているブロックのまとまり。出力面の先が別の道で
    土台とつながっている（輪になっている）関節は、回せないので固定のまま扱います。
  - 関節は、出力面の中心どうしを合わせ、軸の傾きをそろえ、軸まわりの角度を回転角に合わせます（反作用は土台側にもかかります）。
    押し出し・引き込みは、アクチュエーター自身の出力面をずらして先の部分を押します。
  - 電力・信号・配管は今までどおり構築物全体で共有なので、部分に分かれても通ります。
  - 止まって 1 秒たつと、今の形のまま1つの剛体に戻ります。動き出せばまた部分ごとになります。
- ブロックを足したり外したりしたあとも、そのときの形で剛体（または部分ごとの剛体）になります。
- 液体・粘土などの柔らかい素材も、構築物の一部として固まったまま動きます。
- 遠くの構築物のレール（軌道計算）はこのモードでも使います。画面左上に「完全剛体」と表示されます。

### 高速化（numba・複数コア）

`numba`（`pip install -r requirements.txt` で入ります）があると、物理演算の重い部分（形合わせ・結合・当たり判定・
表面の形の計算）を機械語に変換して実行し、構築物ごとの計算を複数の CPU コアで同時に進めます。
大きな構築物（256 ブロック以上）は、その中のブロックごとの計算を複数コアに分けます。

- 初回起動時だけ変換に数十秒かかります（裏で行うので、その間も遊べます。2回目以降は保存済みを使うので数秒）。
- `config/settings.json` の `physics.fast` を `false` にすると使いません。`physics.threads` で使うスレッド数を指定できます（0 = 自動）。
- numba が入っていなくても今までどおり動きます。

## 現時点の制限（今後の拡張ポイント）

- 惑星の地形は距離場＋掘削跡で表現しており、プレイヤーの構築物のような頂点ボクセルではありません
  （掘ることはできますが、地形が崩れたりはしません）。地球型の惑星の水は静止した水面で、流れません。
- 洞窟や掘削跡の詳細な描画には scikit-image が必要です（無い場合は表面の起伏だけを表示）。
- 惑星は固定位置（公転なし）、大気抵抗なし。
- 大きな構築物ほど柔らかくなりやすい（反復計算の回数は `config/settings.json` の physics で調整可）。
- ゲーム内スクリプトのサンドボックスは簡易的なものです。他人のスクリプトは中身を確認してから使ってください。
- 日本語フォントは Windows の メイリオ／游ゴシック 等を自動で使います。見つからない場合は
  `config/settings.json` の `graphics.font` にフォントファイルのパスを書いてください。
